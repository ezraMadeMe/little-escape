# 🎮 Dev Console - Quick Start

## 바로 시작하기

### 1. 서버 실행

```bash
# Backend
cd backend
./gradlew bootRun

# Frontend (새 터미널)
cd frontend
npm run dev
```

### 2. Dev Console 접속

```
http://localhost:5173/dev-console
```

---

## 핵심 기능 3가지

### 1️⃣ 🎲 랜덤 시나리오 생성

클릭 한 번으로 모든 환경 변수를 무작위로 채웁니다.

**사용법**:
1. **"🎲 랜덤 시나리오"** 버튼 클릭
2. 모든 필드가 자동으로 채워짐
3. **"▶️ 시뮬레이션 실행"** 클릭

**언제 사용?**
- 빠른 반복 테스트
- 예외 상황 탐색
- 버그 헌팅

---

### 2️⃣ 📍 위치 프리셋

서울 주요 지역을 원클릭으로 설정합니다.

**프리셋 목록**:
- 📍 성수동
- 📍 강남역
- 📍 홍대
- 📍 여의도
- 📍 서울역

**언제 사용?**
- 특정 지역 테스트
- 장소 데이터 분포 확인

---

### 3️⃣ 🖥️ Debug Logs

백엔드 추천 과정을 실시간으로 확인합니다.

**로그 예시**:
```
[1] 🕒 시뮬레이션 시간: 2025-01-20T14:30:00 (MONDAY, 14시)
[2] 📍 위치: (37.5665, 126.9780), 반경: 10km
[3] ☁️ 날씨: RAIN, 기온: 12.0°C, 미세먼지: GOOD
...
[8] 📅 월요일 - 도서관 미션 제외 (1개 제외됨)
...
[14] ✅ 선택된 장소: 북촌 한옥마을 카페
```

**색상 코딩**:
- 🟢 초록 (✅): 성공/선택
- 🔴 빨강 (❌): 제외/실패
- 🟡 노랑 (⚠️): 경고

---

## 주요 시나리오

### 🌧️ 비오는 날 실내 추천 검증

```
1. 날씨: 🌧️ 비
2. 기온: 12°C
3. 시뮬레이션 실행

✅ 기대 결과: Debug Logs에서 "야외 활동 제한 - 실내 장소만 추천" 확인
```

---

### 📅 월요일 도서관 필터링 검증

```
1. 날짜: 2025-01-20 (월요일) 14:00
2. 위치: 성수동
3. 시뮬레이션 실행

✅ 기대 결과: Debug Logs에서 "월요일 - 도서관 미션 제외" 확인
```

---

### 🌙 야간 전시 제외 검증

```
1. 시간: 23:00 (밤 11시)
2. 시뮬레이션 실행

✅ 기대 결과: Debug Logs에서 "밤 10시 이후 - 전시/공연 미션 제외" 확인
```

---

### 🤫 혼잡도 높을 때 조용한 장소 우선

```
1. 혼잡도: 😵 터짐 (HIGH)
2. 시뮬레이션 실행

✅ 기대 결과: Debug Logs에서 "혼잡도 높음 - 조용한 장소 우선" 확인
```

## UI 구조

### 왼쪽 패널: 입력

**4개 섹션으로 그룹핑**:

1. **🕒 시공간 설정**
   - 날짜/시간, 위치, 반경

2. **🌦️ 환경 변수**
   - 날씨, 기온, 미세먼지, 혼잡도

3. **👤 사용자 페르소나**
   - MBTI, 솔로 레벨, 카테고리

4. **액션 버튼**
   - 🎲 랜덤 시나리오
   - ▶️ 시뮬레이션 실행

### 오른쪽 패널: 결과

- ✅ 추천된 미션
- 📍 추천된 장소
- 📊 통계 (후보 개수)
- 🖥️ Debug Logs (터미널 스타일)

## 문제 해결

### ❌ 서버 연결 오류

**증상**: `Network Error`

**해결**:
```bash
cd backend
./gradlew bootRun
```

---

### ⚠️ 추천 결과 없음

**증상**: `mission: null`

**해결**:
1. 반경을 20km로 늘리기
2. 카테고리 강제 지정 해제
3. 솔로 레벨을 5로 높이기
